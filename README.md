# Diet Calorie Recommendation System

An AI-powered food calorie tracking and diet recommendation application.


## Features

- Food image recognition using Google Gemini AI
- Real-time calorie tracking
- Daily calorie goal monitoring
- Diet recommendations


## Installation

```bash
git clone https://github.com/Chandrkant07/Diet-calorie-recommedation-system.git
cd Diet-calorie-recommedation-system
pip install -r requirements.txt
```


## Usage

1. Launch the app with `streamlit run app.py`
2. Upload or capture a food image
3. View calorie information and recommendations
